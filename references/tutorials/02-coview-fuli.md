# Tutorial 2: CoView 实战 - 半天开发社群福利站

**来源:** 微信公众号教程
**核心案例:** 乔木福利社 (fuli.qiaomu.ai)

## 案例产品功能

| 功能 | 描述 |
|------|------|
| 福利项目管理 | 标题、内容、封面、标签设置，支持 Markdown |
| 邀请码系统 | 每个项目关联邀请码，自动发放或手动发放 |
| 多媒体支持 | Epub/PDF 下载、AI 音乐播放、Skill Zip 包下载 |
| 无限层级评论 | 类似小型 BBS |
| 内容控制 | 是否需要登录、是否自动发邮件 |
| 邮件通知 | 使用 Resend API（免费 3000 封/月，100 封/天） |

## CoView 核心体验

> "体验就跟真的程序员说话，指着屏幕提改动！"

**为什么 CoView 是革命性的：**
- 打字描述需要好几轮才能说清楚
- 录屏可以直接指着页面说"这里不对，改成这样"
- 预测：未来所有 Vibe Coding 工具都会加入类似功能

## Vibe Coding 完整工作流程

**Step 1: 生成需求文档**
1. 先用 Chat 模式描述产品想法
2. 让 AI 生成详细需求文档
3. 模型选择：Claude、Gemini 或 GPT 顶级模型
4. 对话调整直到满意

**Step 2: 发给 YouWare 开发**
1. 把需求文档整个发给 YouWare
2. 进入开发等待时，点击 icon 启用 CoView
3. 首次需开启浏览器录屏和音频权限

**Step 3: 持续对话迭代**
- 用 CoView 录屏指出问题
- 使用 Boost 预设提示词优化
- 核心理念：干中学，不追求完美，先做个垃圾出来，持续迭代

## Boost 功能

对话框上方的 **Boost** 按钮，点击出现三个预设提示词：
- 针对性做了定制强化
- 比自己描述效果好太多
- 大胆去试，效果惊艳

## Logo 和 Favicon 技巧

使用 https://icon.kitchen/ 生成：
1. 选择图标和配色
2. 点击 Download 下载压缩包
3. 上传压缩包到 YouWare 对话框
4. 说："附件是我的网站 Logo 和 favicon，帮我加上去"
5. AI 自动解压、查找、部署

## Google 登录详细步骤

1. 去 https://console.cloud.google.com/auth/overview/create 创建应用
2. 填写 YouWare 给的两个 Callback URL
3. 获取 Client ID 和 Secret
4. 回到 YouWare 填写
5. 网站登录自动出现 Google 登录选项，无需额外开发

## 自定义域名详细步骤

**前提：** Pro 以上会员

**额外设置选项：**
- 从社群隐藏
- 网页不显示 YouWare 徽章

**操作流程：**
1. 进入域名设置
2. 填写子域名或主域名（如 fuli.qiaomu.ai）
3. 点下一步，生成 DNS 配置
4. 复制 DNS 配置到域名管理后台
5. 等待约 10 分钟自动验证通过
