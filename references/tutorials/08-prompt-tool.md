# Tutorial 8: YouBase 创建画像生成 AI 提示词整形工具

**来源:** Note.com（あかり）
**主题:** 用 YouBase 创建 AI 绘图提示词生成网站
**实际案例:** https://eyo2e1srbx.youware.app
**原文语言:** 日文

## 解决的痛点

- 不知道哪个提示词是当初的"神图"
- 无法重现同样的氛围
- 备忘录散落各处，找起来很费时间
- 最后又从头开始试错

## 网站功能

**5个标签页：** Midjourney / NijiJourney / SeaArt / PixAI / General

**选择要素：**
- 用途、被摄体、风格、氛围
- 构图、光线、颜色、质感、负面提示词

**输出：**
- 完成提示词
- 负面提示词
- 短缩版
- Quality Boost 版（增强版）

每个输出框都有 Copy 按钮，一键复制。

## 创建过程

1. 用日语输入指令
2. YouBase 有效化确认 → OK
3. 自动构建
4. **等待约5分钟完成**

## YouBase 的价值

> "サイトやアプリの裏側の仕組みをまとめて用意できるバックエンド"
> （可以统一准备网站/应用后台机制的后端）

对于画像生成 AI：
- 好作品需要**再现性**
- 再现性需要**积累当初的成功经验**
- YouBase 让这种"积累"可以系统化

## 适合人群

- 经常迷失在提示词中的人
- 想开始 AI 副业的人
- 想在家工作慢慢积累的人
- 想增加试错次数来提高收益的人
