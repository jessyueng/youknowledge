# Tutorial 9: "二人だけのアプリ" - 用完即删的浪漫新形式

**来源:** Note.com（ライトクラフト）
**主题:** Remix 功能 + 个人化应用的新可能
**实际案例:** https://mgzbf97hnc2-live.yw.app (越南语情侣纪念日应用)
**原文语言:** 日文

## 发现的应用

一个越南语创建的应用："For my lovely love"
- 情侣纪念日赠送给对方的"网站型情书"
- 回忆照片、两人的历史、用心的信件
- 打包成"专属应用"，只为世界上唯一的恋人

## 新的思考

**传统 SNS 的风险：**
- 如果分手了怎么办？
- 搜索一直能找到怎么办？
- "数字纹身"的不安

**"二人だけのアプリ"的优势：**
- 只有知道 URL 的两人能访问的秘密基地
- 没有 SNS 的认同欲求，没有他人的目光
- 读完后可以删除

## 新理念

> "为了一个人而创建，完成使命后消失的应用"

就像读完后扔进壁炉的纸信一样。
"因为是为你特意做的"这个过程本身就是礼物。

## Remix 功能

YouWare 的 Remix 功能：
- 可以复制这个应用作为模板使用
- 换成自己的回忆照片
- 与恋人分享
