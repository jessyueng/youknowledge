# Tutorial 3: 3小时从零搭建在线艺术博物馆

**来源:** 视频评测
**核心案例:** Every Arts - 在线艺术博物馆
**作者背景:** 设计师，不会写代码的 Vibe Coder

## 视频总结

展示了如何用 YouWare 在 3 小时内从零搭建一个功能完整的在线艺术博物馆网站，包含名画浏览、点赞、留言、登录功能。

## YouWare 核心优势

| 优势 | 说明 |
|------|------|
| 积分退款机制 | 对 AI 生成结果不满意可一键退回积分，不像订阅制"用不用都要付钱" |
| 内置后端 YouBase | 解决大多数 AI 编程工具只能生成前端、无法处理数据库的痛点 |
| 可视化编辑 | 像 PPT 一样直接拖拽修改页面元素 |
| Figma 无缝衔接 | 直接导入 Figma 设计稿生成可运行网站 |

## 传统 AI 编程工具的痛点

1. **订阅费贵且不退** - 需同时订阅多个 AI 模型，生成结果不满意钱也扣了
2. **搞不定数据库** - 前端容易，后端数据库大多数工具没法处理

## 平台功能演示

**工作台入口：**
- 左侧边栏"探索"可查看别人项目（游戏、AI 应用、生产力工具）
- 输入区可写 prompt、上传图片、接入 MCP 工具
- AI 模型可选 Gemini 3 Flash、Claude Sonnet、GPT-5 等，不用单独订阅

**实战 Prompt 示例：**
> "我想做一个叫 Every Arts 的在线博物馆，用户可以浏览梵高、莫奈等名画，可以点赞、留言，需要登录功能。"

**YouBase 数据库视图：**
- 用户表：存储用户信息
- 作品表：存储画作数据
- Secrets：存放 API 密钥等敏感信息
- 未来将开放 API 接口

## 四个实用按钮

| 按钮 | 功能 |
|------|------|
| 刷新预览 | 更新网站后刷新查看 |
| 控制台 | 查看报错和调试信息 |
| 移动端视图 | 预览手机端效果 |
| 可视化编辑 | 像 PPT 一样拖拽修改，改完一键同步上线 |

## Figma 联动

1. 在 Figma 中复制设计稿链接
2. 回到 YouWare 开启 Figma MCP
3. 粘贴链接 → 设计稿直接变成可运行网站
4. 自动加上交互动效

**个人成长启发：**

- 这种"用效果说话"的定价模式可能成为 AI 工具赛道新标准
