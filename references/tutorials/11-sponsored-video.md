# Tutorial 11: YouTube 赞助视频拆解 - 5分钟建课程落地页

**来源:** YouTube 赞助教程视频（约15分钟）
**主题:** 从零开始 5 分钟搭建课程销售落地页
**核心功能演示:** 自然语言建站、Tab 补全、Boost、Rewind、可视化编辑、Remix

## 视频核心信息

作者用 YouWare 演示如何 5 分钟内搭建完整的课程销售落地页，展示了：
- 自然语言建站（不需要拖拽组件）
- 智能 Prompt 补全（按 Tab 采纳建议）
- Boost 一键增强视觉设计
- Rewind 积分退款（不满意可回退）
- 可视化编辑（省积分）
- Remix 基于他人作品创建

## 选题分析

| 成功因素 | 说明 |
|----------|------|
| 具体承诺 | "5分钟建好网站"——时间量化 + 结果明确 |
| 零门槛宣言 | "No coding experience, no developers, just me talking to an AI" |
| 赞助视频标杆 | 不是硬广，而是完整的教程体验 |

**切入点**：不讲功能列表，而是"跟我一起做"的实操教程。

## 痛点与解决方案

| 痛点 | 放大方式 | 解决方案 |
|------|----------|----------|
| 不会写代码 | "I just described what I wanted" | 自然语言交互 |
| 不知道怎么写 prompt | "you don't have to be an expert at prompting" | 智能 prompt 补全 |
| 不知道怎么改好看 | "you're not quite sure exactly what to ask for" | Boost 一键增强 |
| 改了不满意浪费钱 | "Let's say I absolutely hate that" | Rewind 积分退款 |
| 从零开始太难 | "You can find inspiration and remix them" | Remix 模板功能 |

**技巧**：每介绍一个功能前，先描述用户可能遇到的困境，再给出解决方案。

## 视频钩子

> "我刚刚用 5 分钟建好了一个完整的网站。没有写代码，没有请开发，就是我和 AI 聊了聊。结果？有点疯狂。"

**有效原因**：具体时间（5分钟）+ 惊人结果 + 否定预期 + 悬念

## 场景设定技巧

1. **计时器挑战** — 增加真实感和紧迫感
2. **"Let's say..."假设场景** — 自然引出功能点
3. **展示他人作品** — 社会认同 + 想象空间
4. **不完美展示** — 故意展示问题再解决，增加可信度

## Explore 展示的作品案例

- **AI 旅行照片生成器**：上传自拍，选目的地，AI 把你P到大本钟前面
- **模拟交易平台**：可以练习炒股，看收益率和胜率
- **AI 客服网站**：可以真的打电话给 AI 接待员

## GTM 洞察

1. **赞助视频的正确姿势**：不是读广告词，而是完整教程。观众获得价值的同时自然接受产品植入
2. **"省钱"是强卖点**：Rewind 积分退款 + 可视化编辑省积分，反复强调"不浪费钱"——降低用户的付费心理门槛
3. **Explore/Remix 是增长飞轮**：用户作品展示 → 吸引新用户 → 新用户 Remix → 产生更多作品 → 继续吸引
4. **跨平台提示是留存手段**：提到手机 App，让用户在更多场景使用产品，提升粘性
5. **AI 思考过程可视化是信任杠杆**：展示 AI 的 step-by-step 思考过程，让用户相信它真的在"理解"需求
