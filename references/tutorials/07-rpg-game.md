# Tutorial 7: YouBase 开发 Web 游戏 - 登录+存档功能实现

**来源:** Note.com（ネココ）
**主题:** 用 YouBase 实现 RPG 游戏的登录和存档功能
**实际案例:** https://pvoizexm8l.youware.app
**原文语言:** 日文

## 核心目标

创建一个短 RPG 游戏：
- 打败敌人获得经验值和金钱
- 装备升级、等级提升
- 关闭浏览器数据不会消失（存档）
- 在其他设备登录也能继续玩

## YouBase 的比喻解释

| 类型 | 比喻 | 特点 |
|------|------|------|
| 无 YouBase | 游戏厅街机 | 当场玩，关机数据消失 |
| 有 YouBase | Nintendo Switch | 有存档，随时继续，跨设备同步 |

## Prompt 示例

```
- 请创建一个短 RPG（战斗→经验值→升级）
- 使用 YouBase 添加登录功能、游戏存档/读档功能
- 为每个用户保存等级/金钱/道具/当前地图状态/敌人状态
- 下次登录时恢复
- 适配手机 UI
- 如果出错请解释原因并修复
```

## 使用心得

**优点：**
- 初学者也不怕，先出成品再改
- 用文字修正，试错循环快（Vibe Coding）
- YouBase 降低了后端开发门槛
- 巻き戻し（回退）功能：结果不满意可以不消耗积分重试

**注意点：**
- 越讲究越需要试验"怎么说才能传达"
- 一次性加太多功能不如小步迭代稳定
- 可能会出错（但可以贴日志咨询）

## 核心洞察

> YouWare 适合"边做边理解"的人。
