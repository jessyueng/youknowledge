# Tutorial 1: 小白 Vibe Coding 发行全平台&可变现应用指南

**来源:** 微信公众号教程
**核心案例:** Vibe Diary - AI 日记软件 (diary.guizang.ai)

## 案例产品功能亮点

| 功能 | 描述 |
|------|------|
| 全平台可用 | iOS、Android、Mac、Windows 独立窗口运行（PWA） |
| AI 标签系统 | 保存时 AI 自动分析内容，添加时间/地点/人物标签 |
| Todo 模式 | AI 自动判断待办事项，完成后消失 |
| 精细设计 | 莫兰迪色系，每天日记卡片颜色不同 |
| 全能检索 | 支持关键字、日期、标签检索 |
| Markdown 导出 | 单文件导出，方便与 AI 模型交互 |
| 登录注册 | 用户系统 + 邀请码发放核销 |

## 日记设计理念

基于马伯庸和 Karpathy 的 Append-only 笔记模式：
- 只记录事实，不打标签、不分类
- 摩擦低，提高记录积极性
- 单文件几万字，适合 AI 分析
- 相当于个人专属的 ChatGPT 记忆

### 2. YouBase 数据库使用

**场景：** 日记软件需要存储原文和标签

**设计思路：**
- 表1 `diary_entries`：存储日记原文
- 表2 `diary_tags`：存储原文对应的标签（时间、地点、人物）
- 导出时从原文表读取，显示时用带标签的表

**操作流程：**
1. 描述需求后，YouWare 识别到 YouBase 需求
2. 点击按钮开通 YouBase
3. 系统自动完成数据库创建
4. 在右侧预览上方的云朵图标查看数据库

### 3. AI 功能添加（Secrets 安全存储）

**问题：** 前端存储 API Key 有泄露风险

**解决方案：** YouBase 的 **Secrets** 功能

**操作步骤：**
1. 告诉 YouWare："用户创建日记后需要调用 openrouter 的 XX 模型分析内容并创建标签"

### 4. Coview 录屏描述需求

#### 背景：为什么要做 Coview

**问题洞察：**
- 用户非常看重 UI 结果，经常反复调整，但很容易改不对
- 不是 AI 不够聪明，而是沟通低效——**AI 是瞎子**
- AI 不知道用户说的"有问题的地方"在哪里，用户也不知道怎么描述
- 之前的 Agent 仅依赖文字描述和静态代码，无法看到页面真实运行状态

**核心洞察：**
> "Text is terrible at describing spatial problems."
>
> 你说"fix the padding"，AI 在猜是哪个 padding；你说"it feels slow"，AI 看不到卡顿。

**解决方案：** 像拉一个资深工程师到你桌边，指着屏幕说"你看，我点这里，它就会有问题"。

#### 产品价值

**1. 录屏：让 Agent「看见」你所看见的**
- **空间信息**：用鼠标指向具体位置，Agent 跟随鼠标看到精确位置
- **时序信息**：操作顺序、触发时机（文字/图片表达不了）
- **动态行为**：加载过程、动画效果、状态切换
- **上下文环境**：完整还原问题现场

**2. 录音：让 Agent「听懂」意图**
- 边操作边说话，像和真人工程师沟通一样自然
- 传达文字难以描述的内容：
  - 主观感受：太慢、不好看、怪怪的
  - 操作意图：我想做什么、期望什么效果
  - 问题定位：就是这里、这一块、刚才这个操作

**3. 高效且经济**
- AI 能更快更好地解决问题
- Credits 消耗较低
- "What You See Is What You Get" 修复，不用反复试错

#### 为什么 Coview 改变一切

| 优势 | 说明 |
|------|------|
| 消灭猜测游戏 | 看到精确像素区域、时序上下文、触发白屏的具体序列 |
| 捕捉"Vibe" | "This animation feels clunky"、"Make this section pop more"——语音+视频瞬间传达 |
| 严格高效 | 优化了准确性，同时保持低 credits 消耗 |

#### 使用方法

点击输入框右下角录屏按钮 → 允许相应权限 → 演示+说出需求 → 发送

#### 5 个典型使用场景

**Use Case 1: 产品经理 - 快速复刻竞品交互逻辑**
- 场景：发现竞品优秀的用户流程，想快速实现类似效果
- 价值：
  - 完整捕捉操作序列：登录→浏览→筛选→加购→结账
  - 保留时序信息：按钮按下状态、加载动画、页面转场
  - 语音补充意图："这里点击后有渐入效果，我们也要"

**Use Case 2: 设计师 - 精准传达视觉调整需求**
- 场景：觉得页面某个部分"看起来不对"，但难以用文字精确描述
- 价值：
  - 方向性表达："看这里——鼠标悬停时间距太窄"
  - 展示动态效果：hover、滚动视差、微交互

**Use Case 3: 非技术创作者 - "我不知道怎么说，但你看就知道了"**
- 场景：遇到"手机上显示很乱"的问题，不知道技术术语
- 价值：
  - 直接展示问题：用手机录屏展示"按钮跑到底部了"
  - 口语化表达："为什么这里这么丑？""这里看起来怪怪的"

**Use Case 4: 开发者 - 快速复现难以描述的 Bug**
- 场景：遇到"只有特定操作序列才触发"的 Bug
- 价值：
  - 精确复现路径：录屏捕捉触发 Bug 的确切操作序列
  - 时序相关 Bug：竞态条件、动画闪烁、加载异常

**Use Case 5: 老师 - 从教学录像到互动课件**
- 场景：录制软件教程视频，想转换为交互式网页学习模块
- 价值：
  - 保留教学流程：概念讲解→分步演示→常见错误→总结
  - 捕捉操作细节：点哪个菜单、输入什么值、拖到哪里

#### Best Practices

| 原则 | 说明 |
|------|------|
| 聚焦 | 每次录制只针对一个问题 |
| 空间上下文 | 描述时将光标移到对应元素上 |
| 演示触发过程 | 展示导致 Bug 的具体步骤，而非只展示结果 |
| 口语化表达 | "这里感觉有点卡顿"比技术术语更有效 |

#### 效率考量

- Coview 优化的是**准确性**而非速度
- 简单改动（文字编辑、具体 CSS 值）打字可能更快
- 涉及空间引用或时序元素时，Coview 的多模态方式更优

#### 市场差异化

> "录个屏，说句话，Agent 就能修好网站"

- 目前 AI 编码工具中，支持「录屏 + 录音」进行问题诊断与修复的产品极少
- 这种「所见即所得」的交互体验，更符合普通用户直觉，降低产品使用门槛

### 5. UI 设计技巧

**创建一致美观的 UI：**
1. 找一个相似产品的截图或设计稿
2. 发给 YouWare
3. 说："分析这个设计稿，提取设计元素，变成设计 Token 和组件设计，为平台所有设计应用修改，后续修改也基于这套组件和设计样式"

### 6. 登录注册 + 邀请码系统

**Prompt 示例：**
> "为我这个项目添加登录注册系统，并且创建邀请码系统，邀请码单独存在一个数据表里面，没有核验过邀请码的禁止登录。"

**结果：**
- 自动创建登录/注册页面
- 创建 `invitation_codes` 数据表
- 在 YouBase → Users 管理用户
- 在数据库页面管理邀请码

**Google 登录：**
1. YouBase → Users → 右上角 Auth Settings
2. 选择 Google 登录
3. 按照指引视频设置

### 7. PWA 全平台应用

**什么是 PWA：**
> Progressive Web App，进化版网站，类似手机 App 体验，无需应用商店下载。可添加到桌面，独立窗口运行，支持离线使用。

**操作：**
直接告诉 YouWare："将这个网页打包成 PWA 应用，并且做好移动端适配"

**效果：**
- 用户可将网站安装到电脑/手机桌面
- 有独立图标
- 独立窗口运行
- 断网也能用

### 8. Stripe 支付集成

**前提条件：**
- 设计好付费体系
- 做好合规页面（隐私协议等）

**操作：**
1. 告诉 YouWare："帮我集成 Stripe 的支付服务"
2. 集成完毕后填写 Stripe Token
3. Token 自动存储在 Secrets 中

### 9. 自定义域名绑定

**操作步骤：**
1. 点击右上角 "Update"（首次发布按钮名称不同）
2. 在弹窗 Domain 位置点击箭头
3. 点击 "Add Domain" 按钮
4. 输入要绑定的域名
5. 获取参数后，去域名服务商添加 DNS 记录
6. 不清楚如何添加可在 Chat 模式询问 YouWare
