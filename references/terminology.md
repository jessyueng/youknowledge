# Key Terminology

| 术语 | 解释 |
|------|------|
| Vibe Coding | 通过自然语言描述需求，AI 自动生成代码的编程方式 |
| YouBase | YouWare 内置的后端服务和数据库 |
| Coview | 录屏+语音描述需求的功能，解决小白不会描述问题 |
| Secrets | YouBase 中安全存储 API Key 的位置 |
| PWA | Progressive Web App，可安装的网页应用 |
| Design Token | 设计系统中的变量（颜色、字体、间距等） |
| Boost | 预设的优化提示词，针对性定制强化，效果优于自己描述 |
| AutoFix | 自动修复功能，修复不扣积分 |
| Resend API | 邮件发送服务，免费额度 3000 封/月 |
| MCP | Model Context Protocol，让 AI 连接外部工具和数据源的协议 |
| 积分退款 | YouWare 特色机制，对 AI 生成结果不满意可退回积分 |
| 可视化编辑 | 像 PPT 一样拖拽修改页面元素的功能 |
| Credit Care | 自动积分退还功能，不满意时自动返还消耗的积分 |
| AI NoCode | AI 无代码，用自然语言描述需求让 AI 生成工具的方式 |
| Boost Assist | 创建后用聊天方式微调功能的辅助功能 |
| 封闭环境 | YouBase 的私有云环境，数据安全不外泄 |
| Remix | 复制他人项目作为模板使用的功能 |
| Text to website | 用文字描述直接生成网站 |
| Rewind | 巻き戻し，回退功能，可退还消耗的积分 |
