# Getting Started with YouWare

Quick guide to creating your first project in YouWare.

## Overview

YouWare transforms ideas into deployed web applications through AI-powered creation. This guide walks you through the complete workflow.

**Time to first project:** 5-10 minutes

---

## Step 1: Access YouWare

### Options

| Platform | Access |
|----------|--------|
| Web | youware.com |
| iOS | App Store |
| Android | Google Play |
| VS Code | Extension marketplace |
| Cursor | Extension marketplace |

### Create Account

1. Visit youware.com
2. Click "Sign Up" or "Get Started"
3. Register with email or Google
4. Verify your email (optional but recommended)

---

## Step 2: Start a Project

### Option A: Create from Prompt

1. Click "New Project" or "Create"
2. Describe what you want to build
3. AI generates your project

**Example Prompts:**
- "Create a portfolio website for a photographer"
- "Build a landing page for a SaaS product"
- "Make a contact form with email collection"
- "Design a restaurant menu page"

### Option B: Remix Existing Project

1. Browse community gallery
2. Find a project you like
3. Click "Remix"
4. Customize with your content

---

## Step 3: Edit with AI Chat

Chat with AI to modify your project:

**Example Commands:**
- "Change the header color to blue"
- "Add a contact section at the bottom"
- "Make the layout responsive for mobile"
- "Add a newsletter signup form"
- "Change the font to something more modern"

### Tips for Effective Prompts

| Do | Don't |
|-----|-------|
| Be specific | Be vague |
| One change at a time | Multiple unrelated changes |
| Describe desired outcome | Just say "make it better" |
| Reference existing elements | Assume AI remembers everything |

---

## Step 4: Visual Editing

Edit elements directly without prompts:

1. Click the Visual Edit button
2. Select any element on the page
3. Modify text, images, colors, spacing
4. Click Apply to save changes

**What You Can Edit:**
- Text content and formatting
- Images and backgrounds
- Colors and borders
- Spacing and alignment
- Links and buttons

**Benefits:**
- Zero credit cost
- Instant preview
- No coding required

---

## Step 5: Review Code (Optional)

View and edit the generated source code:

1. Click "Code" or toggle to code view
2. Browse HTML, CSS, JavaScript files
3. Make direct edits (subscribers only)
4. Changes reflect in preview

---

## Step 6: Publish

Deploy your project to the web:

1. Click "Publish" or "Share"
2. Choose visibility settings:
   - **Public**: Anyone can view
   - **Private**: Password-protected
3. Get your shareable link
4. Share with the world!

### Your Project URL

Format: `youware.app/your-project-name`

Or set up a custom domain (Pro/Ultra plans).

## Troubleshooting

### AI Not Responding

- Check internet connection
- Verify credits available
- Try simpler prompt
- Refresh the page

### Changes Not Showing

- Check you clicked Apply
- Refresh preview
- Clear browser cache

### Publishing Failed

- Check project has content
- Try again after a moment
- Contact support if persistent
