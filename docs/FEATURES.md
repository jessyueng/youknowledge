# YouWare Features

Comprehensive guide to YouWare's creation, editing, and publishing features.

## Editor Tools

### Visual Editing

Direct UI modification tool for editing website elements without code.

**Capabilities:**
- **Text Editing**: Font size, color, style, alignment
- **Image Editing**: Replace images, adjust sizing
- **Element Styling**: Corner radius, padding, margin, background color
- **Actions**: Add hyperlinks, delete elements

**How to Use:**
1. Click the Visual Edit button in the toolbar
2. Select any element on the page
3. Use the editing panel to make changes
4. Click "Apply" to save or "Discard" to cancel

**Benefits:**
- Zero credit cost for visual edits
- Instant preview of changes
- Keyboard shortcuts (Ctrl/Cmd + Z for undo)
- AI remembers manual edits for future modifications

### CoView (Screen + Voice Recording)

Record your screen while speaking to communicate issues naturally—like sharing a screen with a colleague.

**Why CoView:**
- AI was "blind" before—it couldn't see the actual page state
- Users struggle to describe visual/interaction problems in text
- CoView lets you "show and tell" instead of typing long descriptions

**How to Use:**
1. Click the CoView button in the editor toolbar
2. Navigate to the issue and hover over relevant elements
3. Speak naturally to describe what you want
4. Stop recording and send

**What CoView Captures:**
| Layer | What It Captures |
|-------|------------------|
| Visual | Screen recording frames showing the interface |
| Spatial | Mouse position and movement data |
| Voice | Transcribed audio with tone information |

**Best Use Cases:**
- Animation issues (AI observes exact timing and behavior)
- Layout problems (direct pointing at spacing or alignment)
- Interactive bugs (demonstration of triggering steps)
- Visual polish (subjective feedback like "make this pop more")

**Best Practices:**
- Keep each recording focused on a single problem
- Point at elements while speaking to provide spatial context
- Demonstrate the exact steps that trigger bugs
- Speak conversationally rather than using technical jargon
- Keep clips under 30 seconds for faster processing

**When to Use CoView vs. Text:**
| Use CoView | Use Text |
|------------|----------|
| Pointing at specific elements | Simple text changes |
| Temporal/animation issues | Clear CSS values |
| Subjective feedback ("feels slow") | Code-only modifications |

Automatic version saving for all project changes.

**Features:**
- Automatic version snapshots on every change

**Credit Care Integration:**

## Project Management

### Share & Publish

Publish projects to generate shareable links with access control.

**Publishing Options:**
- **Public**: Anyone with the link can view
- **Private**: Password-protected access (4-character code)
- **Community**: Visible in YouWare community gallery

**Additional Settings:**
- Auto-generated project descriptions
- Remix permission control (allow/disable)
- Remove YouWare badge (Pro/Ultra)
- Mobile app quick-share integration

---

### Remix

Copy and modify existing projects using natural language.

**How Remix Works:**
1. Browse community projects or use a shared link
2. Click "Remix" button
3. Describe changes in natural language
4. AI creates your modified version

**Remix Features:**
- Copy any public project instantly
- Modify content, theme, layout
- Add new sections and features
- Links back to original creator
- Unlimited remix capability

## IDE Integration

### VS Code & Cursor Extension

Publish projects directly from your IDE.

**Features:**
- Seamless VS Code and Cursor integration
- One-click publishing from editor
- No CLI required
- Automatic deployment
- Instant shareable links

**How to Use:**
1. Install the YouWare extension
2. Open your project folder
3. Click the YouWare publish button
4. Get your shareable link instantly
