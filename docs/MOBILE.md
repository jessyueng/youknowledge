# YouWare Mobile App

Full YouWare experience on iOS and Android devices.

## Download

### iOS (App Store)

Search "YouWare" in the App Store.

### Android (Google Play)

Search "YouWare" in Google Play.

---

## Mobile Workflow

Create, edit, and publish projects from your phone.

### Step 1: Start a Project

- Create new projects with AI prompts
- Remix existing community projects
- Access all your projects

### Step 2: Edit with AI

- Chat with AI to make changes
- Voice input for prompts
- Photo integration for visual references

### Step 3: Preview & Iterate

- Real-time preview of changes
- Visual editing available
- Code view for subscribers

### Step 4: Publish & Share

- One-tap publishing
- Share links instantly
- Configure privacy settings

## Mobile-Specific Features

### Voice Input

Dictate prompts instead of typing:
1. Tap the microphone icon
2. Speak your request
3. AI processes your voice command
4. Review and submit

### Photo Integration

Use photos as design references:
1. Tap the photo icon
2. Select from library or take new photo
3. AI analyzes the image
4. Generates matching design elements

### Quick Actions

- Long-press for context menus
- Swipe gestures for common actions
- Pull-to-refresh for updates

## Comparison: Mobile vs Desktop

| Feature | Mobile | Desktop |
|---------|--------|---------|
| AI Chat | Full | Full |
| Visual Editing | Full | Full |
| Code View | Full | Full |
| Code Editing | Limited | Full |
| Multi-file Editing | Limited | Full |
| Voice Input | Yes | No |
| Photo References | Yes | Limited |
| Screen Size | Compact | Full |

### Best Practices

**Use Mobile For:**
- Quick edits on the go
- Idea capture and prototyping
- Sharing and publishing
- Monitoring project status

**Use Desktop For:**
- Complex multi-file editing
- Detailed code work
- Extended development sessions
- Large screen requirements
