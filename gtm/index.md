## YouBase Launch 速查

### 目标受众 & Key Message

| Audience | Pain Point | Key Message |
|----------|------------|-------------|
| SMB | 没钱雇人，不懂技术 | 别再花 $5000 雇人写代码了。$20 搞定 |
| Prosumer | 学 WordPress/Shopify 太难 | 一句话生成，技术门槛为 0 |
| 竞品用户 | Lovable Cloud 额外收费 | 不收"云税"，后端免费包含 |
| AI 极客 | 质疑 AI 代码能否生产环境 | Production-Ready，企业级安全 |

### 核心卖点

1. **Unbeatable Cost-Efficiency** - $20 vs $5000 雇人
2. **Zero-Config Simplicity** - 不用学 Supabase/Vercel
3. **Global Performance** - 300+ 节点，秒级响应
4. **Real Revenue** - 支持 Stripe，上线就能收钱

## CoView Launch 速查

### 核心价值

| 能力 | 解决的问题 |
|------|-----------|
| 录屏 | AI 之前是瞎子，看不到页面真实状态 |
| 录音 | 用户不会描述问题，说不清楚 |
| 组合 | 像跟真人工程师沟通一样自然 |

### 经典表述

> "AI 写代码的能力很强，但是 AI 不知道完整的信息，用户无法精确地描述问题。"

> "录个屏，说句话，Agent 就能修好网站" —— 所见即所得

### Use Cases

1. **PM** - 录屏复制竞品交互逻辑
2. **Designer** - 指着说"这里间距太窄"
3. **非技术用户** - "我不知道怎么说，但你看就知道了"
4. **Developer** - 复现难以描述的 Bug
